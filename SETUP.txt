How to use
- Start a New visit, enter details, take/upload the display photo, and optionally take/upload the actual DR/BO receipt.
- Tap Save photos once: the two images are offered to your device and queued for Drive upload.
- Download photos and manual Save to Gallery also queue both images.
- Use the MAIN Save photos button to upload the pair; the separate receipt save/download controls only save that receipt locally.
- Record sync runs independently; each selected product row for the visit gets the same code and photo links.
- Media Upload Status shows RECEIPT PENDING until the attached receipt finishes, then UPLOADED.
- Confirm no pending uploads before clearing browser storage. Photos waiting to upload are stored in this browser's IndexedDB.
- New visit clears photo previews, but retains already queued uploads. Retaking alone does not change the code.

Retry and storage behavior
- Offline photos stay queued; reconnecting, reloading or Upload / retry photos retries them.
- Failed upload responses do not remove queued photos. An old Apps Script deployment is detected and prompts an update.
- Identical file retries reuse the same Drive file. A retaken/changed image creates a new file and updates the Sheet link;
  previous Drive files remain in the folder. Four-character codes are matching labels, not globally unique IDs.
- Original camera key + media type + code + content hash determine upload identity, not the short code alone.
- If a different code is sent for an existing camera key, the script rejects it rather than mislinking photos.
  Set a new visit date/time for a distinct visit whose other fields match an earlier one.
- Drive links retain the folder's existing access restrictions; this update does not make photos public.
- Maximum upload size: 18 MB per photo. Larger photos still save locally but are not queued for Drive.
- A device share sheet may require Save to Gallery; unsupported browsers show both images to save individually.
- Browser clearing, private browsing or storage eviction can remove pending local photos; keep device copies.
